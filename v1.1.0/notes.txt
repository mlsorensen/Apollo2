
- **Scales reconnect sooner.** Apollo now remembers how your scale identifies itself over Bluetooth, so each reconnect is one steady 10-second listen instead of two 5-second guesses with gaps between them. A scale switched on mid-wait no longer sits unnoticed for up to half a minute.
- **History rows fit on the X 8".** The weight column ("36.2/36g") was cut off on the left on the 8" box; the row text is now sized so every column fits, and the other boards are unchanged.
- **Live graph speed kept through the platform update.** The update changed a processor cache setting that slowed the shot graph on the P4 boards by about 20%; this release restores it, so the graph draws as it did in v1.0.2.
- **Fewer surprise restarts on the P4 boards.** Updated the base platform and the WiFi/Bluetooth radio's firmware; the new radio driver recovers from a rare glitch that could restart the X 8" every few hours. On the first start after updating, the radio updates itself and Apollo restarts once more.
- **Updates that need a computer say so.** If a future release changes the part of the firmware that starts the board, the update notice says it must be installed from a computer with the web flasher, instead of offering an install that can't work.
- **Pair an Acaia Umbra (Umbra firmware 1.0.8).** Apollo can pair with the Umbra the way a Lunar does, keeping its sleep/wake behaviour. Choose it in Settings > Scale > Scan; the first time Apollo restarts once, then asks you to hold the Umbra's button until it blinks magenta.
- **Correct Umbra weight when it's set to ounces.** An Umbra set to oz showed weights 28× too high. It always sends grams, so Apollo no longer converts, and its Unit row is gone — it has no display to change.
- **Scales count as connected once weight arrives.** Home, Tare and Auto shot now wait for the first weight reading, not just the Bluetooth link, so a shot can't arm on a scale that isn't sending yet.
- **Forget no longer risks a restart.** Forgetting a scale could occasionally crash Apollo.
- **P4 boards with no SD card check the slot once.** Searching the empty slot every few seconds disturbed the WiFi/Bluetooth radio, which shares that bus, and could restart the device. The card is now checked at startup and when you ask.
- **New Settings > Apollo > Storage page.** Shows the card's status, make/model, capacity, filesystem and used/free space, with Mount and Unmount buttons; insert a card and tap Mount (or restart), Unmount before taking one out.
